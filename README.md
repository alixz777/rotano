# Rotano - Интернет-магазин ротанга

Проект интернет-магазина по продаже искусственного ротанга. Содержит оригинальную HTML верстку и современное React-приложение.

## Структура проекта

```
project/
├── *.html              # Оригинальные HTML страницы верстки
├── css/                # Оригинальные стили
├── img/                # Изображения
├── fonts/              # Шрифты
├── js/                 # Оригинальные JavaScript файлы
├── react-app/          # React-приложение (готовое к использованию)
│   ├── src/           # Исходный код React
│   ├── public/        # Статические файлы
│   ├── dist/          # Собранная версия для продакшена
│   └── package.json
└── supabase/          # Миграции базы данных
```

## React-приложение

React-версия сайта находится в папке `react-app/`. Это полнофункциональный интернет-магазин с:

- ✅ Главной страницей со слайдером
- ✅ Каталогом товаров
- ✅ Карточками товаров
- ✅ Корзиной
- ✅ Оформлением заказа
- ✅ Интеграцией с Supabase
- ✅ Управлением состоянием через Context API

### Быстрый старт

```bash
cd react-app
npm install
npm run dev
```

Подробная документация в `react-app/README.md`

## База данных

База данных создана в Supabase и содержит:

- **products** - каталог товаров (11 товаров уже добавлено)
- **product_images** - дополнительные изображения
- **orders** - заказы клиентов
- **order_items** - позиции в заказах

Все таблицы защищены Row Level Security (RLS).

## Развертывание

1. Склонируйте репозиторий
2. Настройте переменные окружения в `react-app/.env`:
   ```
   VITE_SUPABASE_URL=your_url
   VITE_SUPABASE_ANON_KEY=your_key
   ```
3. Установите зависимости: `cd react-app && npm install`
4. Запустите dev-сервер: `npm run dev`
5. Или соберите для продакшена: `npm run build`
