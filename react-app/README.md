# Rotano - Интернет-магазин ротанга

React-приложение интернет-магазина по продаже искусственного ротанга с использованием Vite, React Router и Supabase.

## Функциональность

- **Главная страница**: слайдер с акциями, категории продукции, популярные товары
- **Каталог**: список всех товаров с фильтрацией
- **Карточка товара**: подробная информация о товаре, возможность добавить в корзину
- **Корзина**: управление количеством товаров, удаление из корзины
- **Оформление заказа**: форма с данными клиента и выбором способа доставки/оплаты

## Технологии

- **React** - библиотека для создания пользовательского интерфейса
- **Vite** - сборщик и dev-сервер
- **React Router** - маршрутизация
- **Supabase** - база данных PostgreSQL и бэкенд
- **Swiper** - слайдер для главной страницы
- **LocalStorage** - хранение корзины

## База данных

Структура таблиц в Supabase:

- `products` - товары
- `product_images` - дополнительные изображения товаров
- `orders` - заказы
- `order_items` - позиции в заказах

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Настройте переменные окружения в файле `.env`:
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

3. Запустите dev-сервер:
```bash
npm run dev
```

4. Сборка для продакшена:
```bash
npm run build
```

## Особенности реализации

### Управление корзиной
Корзина реализована с помощью React Context API и сохраняется в LocalStorage для персистентности между сессиями.

### База данных
Все товары и заказы хранятся в Supabase. Таблицы защищены Row Level Security (RLS):
- Товары доступны для чтения всем
- Создавать заказы могут все
- Просматривать заказы могут только аутентифицированные пользователи

### Оптимизация
- Изображения загружаются из публичной папки
- CSS минифицирован при сборке
- Используется code-splitting через React.lazy (при необходимости)

## Разработка

Проект создан на основе существующей HTML/CSS верстки и полностью переписан на React с использованием современных подходов и best practices.
